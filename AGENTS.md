# Project Context Capture

After each substantive user request is completed, update `CODEX_CONTEXT.md` with the current keywords, completed work, open issues, and next step.

Use the project helper when a new context entry is needed:

```text
python update_codex_context.py --keywords "..." --progress "..." --next-step "..." --summary "..."
```

Do not record passwords, tokens, private keys, model credentials, or other secrets. Keep entries concise and factual. This is a project-level instruction and applies when this project is opened as the Codex workspace.

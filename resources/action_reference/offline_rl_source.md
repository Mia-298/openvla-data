# Offline RL definition reference

Source: Sergey Levine, Aviral Kumar, George Tucker, Justin Fu, “Offline Reinforcement Learning: Tutorial, Review, and Perspectives on Open Problems”, arXiv:2005.01643, abstract verified 2026-10-12.

Original: https://arxiv.org/abs/2005.01643

Paraphrase: Offline reinforcement learning trains using previously collected data, without collecting additional online interaction data during that training phase. It aims to learn useful policies from that data; reliable generalization to unsupported actions is a key challenge.
